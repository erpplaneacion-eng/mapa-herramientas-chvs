    Tecnologías utilizadas

    Lenguajes

    Python · JavaScript

    Python para la lógica y el manejo de datos; JavaScript, HTML y CSS para las pantallas y los scripts de Google.

    Frameworks web

    Django · FastAPI · Flask · Next.js

    Aplicaciones con usuarios, formularios, paneles y servicios que corren solos.

    Tableros de datos

    Streamlit · Chart.js · Plotly

    Indicadores, cuentas de cobro y resultados de evaluaciones.

    Datos

    PostgreSQL · Google Sheets

    PostgreSQL en producción; Sheets donde las áreas ya trabajaban; SQLite para pruebas.

    Documentos

    ReportLab · pypdf · openpyxl · pandas

    Generar PDF (certificados, formularios, cuentas de cobro) y leer o escribir Excel.

    Automatización

    Selenium · Playwright · EasyOCR

    Descargar boletines y certificados de portales externos, incluido el captcha.

    Inteligencia artificial

    ChatGPT · Visión · RunPod · Claude

    Modelo de lenguaje y modelo de visión para leer y clasificar expedientes, sobre GPU en RunPod; Claude para construir el código y registrar novedades conversando.

    Integraciones

    Sheets · Drive · Gmail · AppSheet

    Bases de personal, archivos en Drive, correos automáticos y apps móviles de supervisión.

    Código y despliegue

    Git · GitHub · Docker

    Historial de cada cambio y empaquetado para publicar en la nube.
